# 逆时订单

> 每一次超时，都是去见你的理由。

**题材**：都市奇幻 · 时间循环 · 悬疑爱情　**作者**：灯下人　**6 章 · 17,803 字**

外卖骑手陈默每次送餐超时都会回到五分钟前。他靠这个能力专接最远的单，直到发现女孩林昭每次点同一家店，备注写着“别超时，我在等五分钟前的你”。他故意超时想见她，却撞破真相：林昭来自未来，是未来的他派来阻止他滥用能力的引路人。两人在闭环中完成最后一次互救，而代价是其中一人必须留在时间裂缝里。
